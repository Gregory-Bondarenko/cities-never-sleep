# Инструкции для ИИ-агентов

Файл читают Claude Code, Cursor, Codex и другие агенты. Правила обязательны для любых изменений в репозитории.

## Продукт

«Города не спят» (Cities Never Sleep): исследование динамики ночной освещённости городов России по VIIRS 2012–2024 в сравнении с населением. Ценность продукта в воспроизводимом исследовательском пайплайне; сайт служит витриной поверх готовых артефактов.

Перед работой полезно прочитать:

- [docs/architecture.md](docs/architecture.md): слои, контракты данных, раскладка каталогов;
- [docs/roadmap.md](docs/roadmap.md): вехи и состав версий;
- [docs/methodology.md](docs/methodology.md): методика и известные ограничения;
- [docs/adr/](docs/adr/): принятые архитектурные решения.

## Процесс

1. Каждое изменение идёт через ветку и pull request в `main`. Прямой push в `main` запрещён.
2. Имя ветки: `<тип>/<кратко>`, типы перечислены в [CONTRIBUTING.md](CONTRIBUTING.md).
3. Сообщения коммитов и заголовок PR по Conventional Commits: `feat(analytics): ...`, `fix(pop): ...`, `docs: ...`.
4. Изменение, заметное пользователю или влияющее на данные, сопровождается записью в `CHANGELOG.md` в разделе `[Unreleased]`.
5. Перед открытием PR должны проходить `uv run ruff check analytics tests` и `uv run pytest -q`.
6. Решение, которое меняет архитектуру, стек или контракт данных, оформляется как ADR в `docs/adr/`.
7. Задача должна быть связана с issue; в описании PR указывается `Closes #N`.

## Архитектурные инварианты

- Поток данных строго однонаправленный: `analytics/` → `data/processed/` и `analytics/exports/` → `web/`.
- Во фронтенде нет расчётов метрик и трендов, только чтение экспортированных артефактов.
- Сырые и промежуточные данные (`data/raw/`, `data/interim/`) не коммитятся.
- Каждый артефакт в `data/processed/` и `analytics/exports/` сопровождается файлом `*.meta.json` с источником, датой сборки и `schema_version`.
- Тесты не ходят в сеть. Сетевые проверки допустимы только в отдельном workflow `network`.

## Стиль кода

- Python 3.12, менеджер окружения `uv`, линтер `ruff` (правила в `pyproject.toml`).
- Пакет лежит в `analytics/citiesneversleep/`, точка входа CLI `cns`.
- Новые источники данных добавляются в `sources/`, обработка в `process/`, метрики в `metrics/`.
- Функции загрузки идемпотентны и пишут манифест с контрольными суммами.

## Стиль документации

Документация пишется на русском языке в деловом регистре.

- Без длинных тире: вместо них двоеточие, запятая или новое предложение.
- Без англицизмов и сленга там, где есть русское слово; устоявшиеся термины (CI, PR, COG, SPARQL) допустимы.
- Без первого лица и без рекламных формулировок.
- Выводы формулируются осторожно («может свидетельствовать», «вероятно»), если они не подтверждены расчётом.
- Ничего не выдумывать: каждая цифра и утверждение о данных подтверждается ссылкой на источник или расчётом.
