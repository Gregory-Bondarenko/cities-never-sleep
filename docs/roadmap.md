# Дорожная карта

Вехи привязаны к версиям продукта. Каждой вехе соответствует milestone на GitHub, задачи ведутся в issues.

Принцип порядка: сначала сквозной результат на простых допущениях (данные → таблица «город × год» → выводы → сайт), затем уточнение методики. Так каждое следующее улучшение проверяется на уже работающей цепочке, а ограничения первой версии явно перечислены в [методике](methodology.md). Обоснование: [ADR-0005](adr/0005-mvp-first-simple-boundaries.md).
