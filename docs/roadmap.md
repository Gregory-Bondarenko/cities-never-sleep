# Дорожная карта

Вехи привязаны к версиям продукта. Каждой вехе соответствует milestone на GitHub, задачи ведутся в issues. Порядок вех фиксирован, сроки ориентировочные.

| Версия | Веха | Критерий готовности |
|---|---|---|
| v0.1.0 | Каркас и загрузчики | `cns fetch` и `cns process-vnl` проходят на чистой машине хотя бы для одного года; CI зелёный |
| v0.2.0 | Качество данных и границы городов | население приведено к контракту; у каждого города есть контур застроенной зоны; ключ `city_id` |
| v0.3.0 | Зональная статистика | набор `city_lights` (город × год) для 2012–2024 с флагами качества |
| v0.4.0 | Методика и поправки | проверен шов шкалы 2021/2022, учтены северные широты и факелы, сверка с Black Marble |
| v0.5.0 | Анализ | тренды, классы динамики, сравнение с населением, ноутбуки с выводами |
| v0.6.0 | Витрина | карта городов и карточка города на GitHub Pages по экспортам |
| v1.0.0 | Публичный MVP | воспроизводимый прогон одной командой, опубликованная методика, сайт |

## v0.1.0. Каркас и загрузчики

- [x] Каркас репозитория, CLI `cns`, минимальный CI.
- [x] Загрузчик VNL с Zenodo, обрезка по России.
- [x] Загрузчик населения из Wikidata.
- [x] Документация процесса и архитектуры.
- [x] Тесты не зависят от сети.
- [x] Пробный прогон загрузки и обрезки VNL за 2013 год на раннере GitHub (#4).

## v0.2.0. Качество данных и границы

- Расширение SPARQL-запроса на подклассы «города», решение по городам Крыма.
- Нормализация и проверка ОКТМО, устранение конфликтов значений населения.
- Метаданные артефактов по контракту из [architecture.md](architecture.md).
- Контуры городов: OSM и маска застроенной зоны, выбор фиксируется в ADR.

## v0.3.0. Зональная статистика

- Расчёт суммы излучения и площади освещённой зоны по городу и году.
- Флаги качества: малое число ясных месяцев, выбросы, пропуски.
- Хранение в Parquet, при необходимости DuckDB.

## v0.4.0. Методика и поправки

- Эмпирическая проверка деления 2012–2021 на 10 по стабильным пикселям.
- Оценка влияния полярного дня и снежного покрова на северные города.
- Проверка маскирования факелов попутного газа.
- Сверка с NASA Black Marble VNP46A4.

## v0.5.0. Анализ

- Тренды (Манн–Кендалл, наклон Сена), точки разладки.
- Классы динамики: растёт, стабилен, гаснет.
- Сопоставление динамики света и населения, квадранты.

## v0.6.0. Витрина

- Утверждение стека фронтенда через ADR.
- Карта городов, карточка города, сравнение лет.

## v1.0.0. Публичный MVP

- Полный прогон `make all` на чистой машине.
- Методика в `docs/methodology.md` в финальной редакции.
- Сайт на GitHub Pages, тег и GitHub Release.
