# Источники данных и лицензии

Краткий справочник для недели 1. Подробный разбор — в плане проекта (store).

## Ночные огни (VIIRS VNL)

| | |
|---|---|
| Набор | OpenGeoHub / EOG VNL V2.1, годовые композиты 500 м |
| Где | [Zenodo 17294744](https://zenodo.org/records/17294744) |
| Годы MVP | 2012–2024 (файлы `nightlights.average_viirs.v21_m_500m_s_<YYYY>…tif`) |
| Лицензия | CC-BY 4.0 |
| Доступ | без логина |
| Локально | сырые — `data/raw/vnl/` (не в git); обрезка РФ — `data/interim/vnl/` |

**Обрезка:** bbox `19…180°E, 41…82°N` + окно Чукотки `-180…-168°E`.

**Шкала:** в описании набора обещана ×10, но в файлах 2022–2024 значения уже в нВт. CLI по умолчанию делит 2012–2021 на 10 (`cns process-vnl`).

## Население

| | |
|---|---|
| Источник | [Wikidata SPARQL](https://query.wikidata.org/) |
| Что тянем | города РФ (`P31` = city/town, `P17` = Россия) с ОКТМО (`P764`) и рядом `P1082` + дата `P585` |
| Лицензия | Wikidata — CC0; исходные цифры — бюллетени Росстата |
| Локально | `data/processed/population/*.parquet|csv` (маленькие, можно коммитить) |

Сайты Росстата с зарубежного IP часто недоступны; Wikidata — рабочий обход для MVP. Ручная сверка XLSX — позже (`data/manual/`).
