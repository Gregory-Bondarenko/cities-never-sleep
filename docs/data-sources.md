# Источники данных и лицензии

Справочник по внешним источникам. Ограничения данных и их влияние на выводы описаны в [methodology.md](methodology.md).

## Ночная освещённость (VIIRS VNL)

| | |
|---|---|
| Набор | OpenGeoHub / EOG VNL V2.1, годовые композиты 500 м |
| Где | [Zenodo 17294744](https://zenodo.org/records/17294744) |
| Годы | 2012–2024, файлы `nightlights.average_viirs.v21_m_500m_s_<ГГГГ>…tif` |
| Лицензия | CC-BY 4.0 |
| Доступ | без регистрации |
| Локально | сырые файлы в `data/raw/vnl/`, обрезка по России в `data/interim/vnl/` (в git не попадают) |

**Обрезка.** Прямоугольник 19…180° в. д., 41…82° с. ш. и отдельное окно Чукотки за 180-м меридианом: 168…180° з. д., 62…72° с. ш.

**Шкала.** В описании набора указан множитель 10, однако в файлах 2022–2024 годов значения уже в нВт/см²/ср. По умолчанию `cns process-vnl` делит значения 2012–2021 годов на 10. Допущение требует эмпирической проверки (см. методику).

## Население

| | |
|---|---|
| Источник | [Wikidata SPARQL](https://query.wikidata.org/) |
| Что запрашивается | города РФ (`P31` = Q7930989, `P17` = Россия) с ОКТМО (`P764`), рядом численности `P1082` и датой `P585` |
| Лицензия | Wikidata под CC0, исходные значения из бюллетеней Росстата |
| Локально | `data/processed/population/ru_cities_population.{parquet,csv}` |

Сайты Росстата часто недоступны с зарубежных IP, поэтому для MVP выбрана Wikidata ([ADR-0002](adr/0002-population-from-wikidata.md)). Ручные выгрузки XLSX для сверки хранятся в `data/manual/`.
