# ADR-0006. Территориальный охват выборки городов

- Статус: Принято
- Дата: 2026-10-30
- Связанные issues: #5

## Контекст

Выборка городов строилась по Wikidata с условием «страна = Россия» (P17 = Q159). Города Республики Крым, Севастополя, Донецкой и Луганской Народных Республик, Запорожской и Херсонской областей в Wikidata, как правило, не имеют такого значения страны и в выборку не попадали.

Продукт ориентирован на пользователей из Российской Федерации, территориальный охват определяется по административно-территориальному устройству согласно законодательству Российской Федерации.

## Решение

1. В выборку включаются города всех субъектов Российской Федерации согласно законодательству РФ, включая Республику Крым, Севастополь, ДНР, ЛНР, Запорожскую и Херсонскую области, если по ним есть данные.
2. Признак включения: наличие у объекта кода ОКТМО (P764). ОКТМО является российским классификатором, и наличие кода означает учёт муниципального образования в российской системе.
3. Запрос состоит из двух ветвей, ветвь фиксируется в столбце `coverage` справочника городов:
   - `p17_russia`: класс «город» (Q7930989), страна Россия, есть ОКТМО;
   - `oktmo_only`: класс «город» или его подкласс, есть ОКТМО, страна Россия в Wikidata не указана.
4. Объекты с кодом ОКТМО, не являющиеся территорией субъектов РФ, исключаются явным списком `EXCLUDED_CITIES` с указанием причины. На 30.10.2026 в списке Байконур (территория Республики Казахстан, арендованная Российской Федерацией).
5. Состав ветви `oktmo_only` проверяется вручную при каждом обновлении данных: в описании PR приводится список городов ветви.

## Последствия

- Первая выгрузка по этому правилу (30.10.2026) добавила 7 городов Республики Крым и Севастополя: Симферополь, Севастополь, Керчь, Евпатория, Джанкой, Белогорск, Старый Крым. Остальные города Крыма, а также города ДНР, ЛНР, Запорожской и Херсонской областей в Wikidata не имеют кода ОКТМО и правилом не охватываются; их добор ведётся отдельной задачей.

- Столбец `coverage` описывает только происхождение записи в Wikidata и используется для контроля качества выгрузки.
- Ряды населения по этим территориям в Wikidata могут быть короче или отсутствовать; такие города получают класс «мало данных» по населению, но участвуют в анализе освещённости.
- Методические ограничения для этих территорий описаны в [methodology.md](../methodology.md).
