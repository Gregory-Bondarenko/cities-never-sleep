# ADR-0009. Витрина: одна страница без сборщика, three.js и данные из выгрузок

- Статус: Принято
- Дата: 2026-11-02
- Заменяет: раздел «Фронтенд» в [ADR-0004](0004-stack.md)

## Контекст

К вехе v0.5.0 витрина прошла три итерации прототипа (#39). Итоговая концепция: каждый город показан точкой на ночном снимке, на остановках сюжета точки перестраиваются из карты в графики (распределения изменений, диаграмма рассеяния), в конце открывается свободное исследование с поиском и карточкой города. Сцене нужен WebGL; остальная страница статична.

## Решение

1. Витрина состоит из одной HTML-страницы `web/src/index.html` с разметкой, стилями и модульным скриптом. Сборщика (Vite, webpack) и npm-зависимостей нет.
2. Трёхмерная сцена строится на three.js 0.169, загружаемом через import map с cdn.jsdelivr.net. Шрифт Geologica с Google Fonts.
3. Данные загружаются из файлов, которые собирает аналитика: `cities.json`, `coastline.json`, `lightmap_<год>.png` и метаданные. `web/build.py` только копирует их в `web/dist/data/`.
4. Витрина не рассчитывает метрики: изменения год к году, медианы и классы приходят из выгрузки. Допускается только перевод значений в координаты и цвета.
5. Цифры в тексте страницы проверяются тестом `tests/test_web_copy.py` по данным.
6. Публикация: workflow `pages` на каждое изменение `web/**` или `analytics/exports/**` в `main`.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Одна страница, three.js с CDN | нет сборки и зависимостей, страница читается целиком, быстрый цикл правок | зависимость от CDN, весь код в одном файле |
| Vite + TypeScript + MapLibre + deck.gl | типизация, модули, готовые картографические слои | сборка и зависимости ради одной страницы; MapLibre тянет подложку тайлов, которая не нужна поверх ночного снимка |
| React-приложение | компоненты, экосистема | избыточно для одной сцены и пяти текстовых блоков |

## Дополнение от 12.11.2026

Приёмы оформления (появление текста, счётчики, бегущий луч по рамке, подсветка под курсором, расходящиеся кольца, эффект расшифровки названия) взяты как идеи из открытых библиотек компонентов Magic UI, Aceternity UI, React Bits, Animata, Eldora UI и Uiverse и реализованы на чистом CSS и JavaScript без подключения этих библиотек: они рассчитаны на React и потребовали бы сборщика. Выбранный город хранится в `localStorage` браузера, на сервер ничего не передаётся.

## Последствия

- Сайт работает с любого статического хостинга; локально: `python3 web/build.py && python3 -m http.server -d web/dist`.
- При росте страницы код сцены выносится в отдельные модули `web/src/*.js`; это не требует сборщика.
- Обновление данных автоматически пересобирает сайт.
