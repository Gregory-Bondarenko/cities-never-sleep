# ADR-0004. Технологический стек

- Статус: Предложено
- Дата: 2026-10-30

## Контекст

Стек описан в [stack-proposal.md](../stack-proposal.md) как рабочая гипотеза. Часть уже используется в коде, остальное требует решения до соответствующих вех.

## Решение

Утверждено сейчас, потому что уже используется в коде:

- Python 3.12, `uv`, `typer`, `httpx`, `rasterio`, `numpy`, `pandas`, `pyarrow`;
- качество: `ruff`, `pytest`, GitHub Actions.

Откладывается до вехи, в которой понадобится:

| Область | Кандидаты | Веха решения |
|---|---|---|
| Зональная статистика | `exactextract`, `geopandas` | v0.2.0 |
| Хранилище | Parquet или DuckDB | v0.3.0 |
| Статистика трендов | `pymannkendall`, `ruptures`, `statsmodels` | v0.5.0 |
| Фронтенд | Vite + TypeScript, MapLibre GL, deck.gl | v0.6.0 |

## Последствия

- Новая зависимость из списка отложенных добавляется только вместе с обновлением этого ADR или новым ADR.
