# Архитектурные решения (ADR)

Каждое существенное решение по архитектуре, стеку, источникам данных или контрактам фиксируется отдельным файлом. Решения не переписываются задним числом: если решение меняется, создаётся новый ADR со статусом «Принято», а старый получает статус «Заменено ADR-NNNN».

## Формат

Имя файла: `NNNN-краткое-название.md`. Шаблон: [0000-template.md](0000-template.md).

Статусы: «Предложено», «Принято», «Отклонено», «Заменено».
