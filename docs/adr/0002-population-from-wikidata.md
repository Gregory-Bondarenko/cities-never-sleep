# ADR-0002. Население из Wikidata вместо прямой выгрузки Росстата

- Статус: Принято
- Дата: 2026-10-29

## Контекст

Сайты Росстата часто недоступны с зарубежных IP, в том числе из CI. Бюллетени публикуются в XLSX с меняющейся структурой, автоматический разбор нестабилен.

## Решение

Основной источник населения для MVP: Wikidata SPARQL (лицензия CC0). Ручные выгрузки Росстата хранятся в `data/manual/` и используются для сверки.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Wikidata SPARQL | доступен из любой сети, есть ОКТМО и ряды по годам | неоднородное происхождение значений, ошибки в ОКТМО, неполный охват |
| Росстат XLSX | первоисточник | нестабильный доступ и формат, ручной труд |
| Сторонние очищенные наборы | готовая очистка | неясная актуальность и лицензия |

## Последствия

- Нужна проверка качества: формат ОКТМО, дубли, противоречивые значения (веха v0.2.0).
- Охват выборки зависит от модели данных Wikidata; решение по городам Крыма и подклассам принимается отдельно.
