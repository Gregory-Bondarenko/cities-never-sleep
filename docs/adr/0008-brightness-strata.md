# ADR-0008. Тренды относительно городов сопоставимой яркости

- Статус: Принято
- Дата: 2026-10-30
- Дополняет: [ADR-0007](0007-series-harmonization.md)

## Контекст

Классы по национальному индексу (ADR-0007) систематически зависят от исходной яркости города. По 1 068 городам и децилям медианной суммы излучения:

| Дециль | «Растёт» | «Гаснет» |
|---|---|---|
| 1 (самые тусклые) | 59% | 6% |
| 5 | 19% | 25% |
| 8 | 10% | 38% |

Возможные объяснения: реальный рост освещённости малых городов с низкой базы (например, переход на светодиодное освещение); изменение порога маскирования фона в наборе VNL по годам, которое сильнее влияет на тусклые пиксели; обрезка ярких пикселей общим порогом. Без внешней сверки эти объяснения не различаются.

## Решение

1. Города делятся на децили по медиане суммы излучения за все годы. Если городов меньше 300, число страт уменьшается так, чтобы в страте было не меньше 30 городов.
2. Для каждой децили строится свой индекс тем же способом, что и национальный (ADR-0007).
3. Основной класс `lights_class` строится по ряду относительно индекса своей децили: «растёт» означает рост быстрее городов сопоставимой яркости.
4. Класс относительно национального индекса сохраняется в `lights_class_national`, номер децили в `brightness_decile`.
5. Систематическое различие динамики между децилями описывается в выводах как наблюдение, требующее проверки (Black Marble, v0.6.0), а не как результат.

## Последствия

- Доли классов по децилям выравниваются: «растёт» 15–23%, «гаснет» 14–26%.
- Классы по децилям и по национальному индексу совпадают у 80% городов.
- Вывод «малые города светлеют быстрее крупных» в первой версии не делается.
