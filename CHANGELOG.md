# Журнал изменений

Все заметные изменения проекта «Города не спят» (Cities Never Sleep) фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/). Правила выпуска описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## [Unreleased]

### Added

- Поправка на повторяющуюся региональную составляющую межгодовых колебаний яркости (ADR-0010, модуль `metrics/regional.py`): первая главная компонента сглаженных годовых полей объясняет 67% их дисперсии, её сумма за период около нуля. Межгодовой шум относительных рядов снижается примерно на 16%.
- Столбцы `lights_rel_pct_per_year_noadj` и `lights_class_noadj`, параметры компоненты в метаданных; схема `city_trends` 1.3.0.

### Changed

- Классы яркости считаются по скорректированным рядам: растёт 224 города (было 207), гаснет 264 (было 232), стабильны 579 (было 628). Переходов между «растёт» и «гаснет» нет. Ряд `lights_rel` в выгрузке для витрины скорректирован, схема выгрузки 1.1.1. Цифры на витрине и в `docs/findings.md` обновлены.
- Проверка ступеньки 2021 года (#10): ступенька неоднородна по территории, но не создаёт ложных относительных трендов (ранговая корреляция трендов с поправкой и без 0,993).

## [0.5.0] - 2026-11-02

Веха «Витрина»: сайт с сюжетом по данным и свободным исследованием городов опубликован на GitHub Pages (<https://gregory-bondarenko.ru/cities-never-sleep/>).

### Added

- Выгрузка для витрины, схема 1.1.0: изменения год к году `yoy` по городам и блок `story.jump` с медианой и долей растущих городов; расчёты перенесены из витрины в аналитику (ADR-0001).
- Береговая линия `analytics/exports/coastline.json` из Natural Earth 1:50m, скрипт `scripts/coastline.mjs`.
- Ночной снимок для витрины: `cns export-lightmap --year` → `analytics/exports/lightmap_<год>.png` (максимум по блокам 10×10, логарифмическая шкала) и источник `lightmap` в `data-refresh`.
- Витрина `web/src/index.html`: города точками на ночном снимке, сюжет по прокрутке с перестроением точек в графики, поиск и карточка города; сборка `web/build.py`, публикация на GitHub Pages workflow `pages` (ADR-0009).
- Тест `tests/test_web_copy.py` сверяет цифры в тексте витрины с выгрузкой.

## [0.4.0] - 2026-10-30

Веха «Анализ»: тренды относительно городов сопоставимой яркости, флаг точечных источников, документ с выводами и выгрузка для витрины.

### Added

- `docs/findings.md`: результаты первой версии, все числа воспроизводятся `scripts/findings.py`.
- Выгрузка для витрины `cns export-web` → `analytics/exports/cities.json` (схема 1.0.0): классы, флаги, ряды относительной яркости, суммы излучения и населения по годам.
- Флаг точечного источника `flag_point_source` в `city_trends` (схема 1.2.0): максимальная яркость пикселя выросла более чем в 10 раз.

### Changed

- Классы яркости строятся относительно городов той же децили медианной яркости (ADR-0008): по национальному индексу тусклые города систематически «росли», яркие «гасли». Новые столбцы `brightness_decile`, `lights_nat_pct_per_year`, `lights_class_national`; схема `city_trends` 1.1.0.

## [0.3.0] - 2026-10-30

Выпуск включает вехи v0.2.0 (города и границы) и v0.3.0 (зональная статистика): справочник 1 068 городов с координатами, правило выбора населения, круговые контуры, яркость по городам за 2012–2024 годы с согласованием рядов и первые тренды.

### Added

- Workflow `release`: тег и GitHub Release создаются автоматически при попадании в `main` релизной версии; текст берётся из `CHANGELOG.md` (`scripts/release_notes.py`).
- Проверка ОКТМО (`validate/oktmo.py`): коды нормализуются, некорректные помечаются статусом и не отбрасываются. В текущей выгрузке некорректный код у одного города (Дмитриев), 8-значные коды у Москвы и Санкт-Петербурга (#6).
- Общий модуль метаданных артефактов `meta.py` (#8).
- ADR-0005: сквозной результат раньше поправок методики, круговые контуры городов до v0.6.0.
- Справочник городов `cities/ru_cities` (схема 1.0.0): координаты P625, последнее население; команда `cns fetch-pop` выгружает оба набора.
- Выбор одного значения населения на город и год (#7): столбцы `rank`, `method`, `is_primary`, `n_values`, `is_conflict`; схема набора населения 1.1.0.
- Радиус кругового контура города `process/boundaries.radius_km` (ADR-0005).
- ADR-0006: территориальный охват по законодательству РФ, включая Республику Крым, Севастополь, ДНР, ЛНР, Запорожскую и Херсонскую области; отбор городов по наличию ОКТМО, столбец `coverage` в справочнике городов (схема 1.1.0) (#5).
- Тренды `metrics/trends.py` и команда `cns build-trends`: наклон Сена и тест Манна–Кендалла на логарифмах, национальный индекс, классы динамики относительно типичного города, сопоставление с населением; набор `trends/city_trends` (ADR-0007).
- ADR-0007: общий порог яркости 3 276,7 для всех лет и относительные тренды из-за разного предела хранения и ступеньки 2021 года в VNL; столбец `sol_unclipped` в `city_lights` (#10).
- Workflow `data-refresh`: выгрузка данных на раннере GitHub с пушем в отдельную ветку для PR.
- Зональная статистика `metrics/zonal.py` и команда `cns build-lights`: набор `lights/city_lights` (схема 1.0.0), сумма излучения с весом площади пикселя в кругах 0,5·r, r и 2·r, флаги пропусков и значений у предела хранения; источник `lights` в `data-refresh`.

### Fixed

- Тренд населения оценивается при 5 и более годах вместо 8: у 41 из 149 городов с населением больше 100 тыс. ряд в Wikidata короче 8 лет.
- Байконур исключён из выборки: код ОКТМО есть, но территория не относится к субъектам РФ (ADR-0006).
- Запрос городов по ADR-0006 падал по таймауту Wikidata из-за обхода всех подклассов «города»; порядок выполнения задан явно. Workflow `data-refresh` теперь не скрывает ошибку команды.

### Changed

- **Несовместимо:** набор `population/ru_cities_population` переведён на схему 1.0.0. Столбец `wikidata_id` переименован в `city_id`, добавлен `oktmo_status`, метаданные приведены к контракту (`schema_version`, `built_at`, `package_version`, `fetched_at`); вместо полного списка лет хранятся `year_min`, `year_max`, `n_years` (#6, #8).
- Версия в коде поднята до `0.2.0.dev0`.
- Дорожная карта: порядок вех изменён на «города → статистика → анализ → витрина → методика», добавлены ориентировочные даты.
- Actions обновлены до версий на Node 24: `actions/checkout@v7`, `actions/upload-artifact@v7`, `astral-sh/setup-uv@v10.3.3` (закреплён на точной версии, так как мажорные теги больше не публикуются) (#18).

## [0.1.0] - 2026-10-30

Первый выпуск: каркас, загрузчики данных, обрезка VNL по России, процесс разработки. Пробный прогон за 2013 год пройден на раннере GitHub (#4).

### Added

- Каркас репозитория: `pyproject.toml` (uv), лицензия MIT, `.gitignore`, `Makefile`, CLI `cns` (typer).
- Раскладка «аналитика → артефакты → витрина»: `analytics/`, `data/processed/` и `analytics/exports/`, `web/`.
- Загрузчик годовых VIIRS VNL с Zenodo [17294744](https://zenodo.org/records/17294744) (`cns fetch-vnl`).
- Обрезка COG по прямоугольнику России и окну Чукотки, деление на 10 для 2012–2021 (`cns process-vnl`).
- Загрузчик населения городов РФ из Wikidata SPARQL с ОКТМО (`cns fetch-pop`), результат в `data/processed/population/`.
- Документация: README, `docs/data-sources.md`, `docs/stack-proposal.md`, CONTRIBUTING, минимальный CI.
- Документация продукта: архитектура и контракт артефактов (`docs/architecture.md`), дорожная карта по версиям (`docs/roadmap.md`), методика с известными ограничениями данных (`docs/methodology.md`).
- Реестр архитектурных решений `docs/adr/` с ADR-0001…0004.
- Инструкции для ИИ-агентов `AGENTS.md` и `CLAUDE.md`.
- Шаблоны pull request и issues (ошибка, новая возможность, проблема с данными).
- Тесты загрузчиков VNL и Wikidata на подменённом HTTP, тесты обрезки и нормализации шкалы на синтетическом растре; сетевые запросы в тестах заблокированы (#14).
- Workflow `network`: еженедельная и ручная проверка доступности Zenodo и Wikidata (#14).
- Workflow `smoke`: ручной пробный прогон загрузки и обрезки VNL за выбранный год и загрузки населения на раннере GitHub; сводка в отчёте запуска (`scripts/smoke_report.py`).

### Changed

- Обязательный CI больше не обращается к сети: только `ruff`, `pytest` и проверка CLI; зависимости ставятся строго по `uv.lock` (#14).
- `CONTRIBUTING.md`: префиксы веток, Conventional Commits, squash merge, порядок релиза; исправлен путь к `__init__.py`.
- `README.md`: навигация по документации, значок CI.
